# Kate voice assistant (ASR -> LLM -> TTS -> ESP32)
# Python 3.12
#
#   python -m venv kate-env
#   kate-env\Scripts\activate      (Windows)   /   source kate-env/bin/activate   (Linux/macOS)
#   pip install -r requirements.txt
#
# GPU note: ASR and TTS use CUDA when PyTorch can see a GPU and fall back to the
# CPU otherwise (ASR also needs flash-attn for FlashAttention 2, else it uses
# PyTorch SDPA). For GPU use, install a PyTorch build for your CUDA version:
#   https://pytorch.org/get-started/locally/
# Then install a matching flash-attn wheel (optional, not on PyPI for every
# CUDA/torch combo, e.g. on Windows):
#   pip install flash-attn --no-build-isolation
# Force a backend with KATE_ASR_DEVICE=cpu / KATE_ASR_ATTN=sdpa if needed.
#
# The LLM itself is not a dependency here: LLM/main.py talks to LM Studio on
# http://127.0.0.1:1234, which you run separately.
